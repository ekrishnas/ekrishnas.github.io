### 1️⃣ Push to GitHub

```powershell

git branch -M main
git push -u origin main
```

### 2️⃣ Deploy to Vercel (Easiest!)

**Option A - Fastest (Recommended):**
1. Go to https://vercel.com
2. Click "New Project"
3. Select your GitHub repo
4. Click "Deploy"
5. ✨ Done! Your portfolio is live in 2 minutes!

**Option B - CLI:**
```powershell
npm install -g vercel
vercel
# Follow the prompts
```
