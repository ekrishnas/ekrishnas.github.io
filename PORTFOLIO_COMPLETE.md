## 🚀 How to Deploy in 3 Steps

### Step 1: Push to GitHub (5 minutes)
```powershell
# Create new repo at https://github.com/new
# Name: portfolio (or any name you want)
# Make it PUBLIC

cd c:\Users\eswarabhatla_saikris\Downloads\Code\portfolio-nextjs

# Replace URL with your actual GitHub repo URL
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git
git branch -M main
git push -u origin main
```

### Step 2: Deploy to Vercel (2 minutes)
1. Go to https://vercel.com
2. Click "New Project"
3. Select your GitHub repository from the list
4. Click "Deploy"
5. **✨ Done!** Your portfolio is live!

**Your URL will be:** `https://your-project.vercel.app`

### Step 3: Share! (Instant)
- Update LinkedIn profile with portfolio URL
